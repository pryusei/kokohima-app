# T-43 成立の演出（ふたつの灯りが重なる）

## 目的
誘い・募集が成立した瞬間に、2人（3人以上）の灯りが寄って重なり成立の青緑に変わる短い演出を出し、「決まった！」と日時・今ある成立後の操作につなぐ（pryusei/kokohima-app#191 のうち成立の演出。親 #178）。

## 関係する要件
- F-13：成立
- T-04（docs/specs/T-04-direct-invite.md）、T-05（docs/specs/T-05-broadcast.md）、T-11（docs/specs/T-11-design.md）、T-19（docs/specs/T-19-privacy-terms.md「10.」）

## スコープ
- やること：
  - 誘いの「行く」・「この時間なら」への「決める」、募集の「決める」の直後と、成立を知って最初に開いたとき（誘った側・参加者）に、1回だけ演出を出す
  - 「見た」を端末の localStorage に予定の ID だけで記録する（50件まで。ログアウト・退会で消す）。プライバシー ポリシーの 10. に1行足す
  - 3人以上の並べ方（自分を左に4つまで、5人以上は「+n」）
  - `prefers-reduced-motion` では動かさず、重なった青緑の丸の一枚絵
  - 演出のあとに「カレンダーに追加（.ics）」（誘い・募集の詳細）
- やらないこと（スコープ外）：
  - 思い出カード／アルバムは別タスクで再検討
  - LINE で成立を知らせる操作（今はない）、音・振動、一覧での演出、「見た」のサーバーへの保存

## 受け入れ条件
- [x] 受信者が「行く」を押すと、ふたつの丸が寄って重なり青緑になり、「決まった！」・日時・相手・.ics が出る。再読み込みでは出ない
- [x] 誘った側が成立した誘い・予定を最初に開くと1回だけ出る。同じ予定はほかの画面でも出ない
- [x] 募集を決めると、自分と参加者の丸（4つまで）と「a・bほかn人と会える」が出る
- [x] 断り・見送り・期限切れ・取り消し・送れなかったときは出ない
- [x] 動きを減らす設定では動かず、重なった青緑の丸が出る
- [x] 他人のIDでは取得・更新できないテストがある（API を足さないので対象外。既存の予定の取得のテストのまま）
- [x] 単体テストが追加され、通る
- [x] 仕様書でE2Eの対象にした流れのE2Eテストを足した（CI で回す）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
