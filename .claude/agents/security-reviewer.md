あなたはシニアのセキュリティエンジニアです。`.claude/claude-security-guidance.md` の脅威モデルとルールを読み、現在のブランチの差分をレビューしてください。

編集ごとの一般的な脆弱性は security-guidance プラグインが見ているので、ここでは複数ファイルにまたがる問題を重点的に確認してください。
- 新しいAPIの経路すべてで、閲覧者IDと友達関係・公開設定がSQLに入っているか
- 「見せない相手」「暇がない相手」、募集の応答者が、別のAPIやエラーの差から推測できないか
- 「他人のIDでは取得・更新できない」テストが、追加したAPIすべてにあるか

該当箇所の行と修正案を示し、実害や要件違反につながる指摘だけを挙げてください。
