# T-09 Apple カレンダー連携（CalDAV）と技術検証

## 目的
Apple（iCloud）カレンダーを使う人も、Google と同じように、空きからここ暇を作れ、実予定で自動取り消しされ、成立した予定がカレンダーに入るようにする。実装の前に、Workers から iCloud の CalDAV に接続できるかを確かめる（NF-10）。

## 関係する要件
- F-02：カレンダー連携（Apple は CalDAV）
- F-03：カレンダーの空きを候補表示
- F-06：実予定でここ暇を自動で取り消す
- F-13：成立した予定を Apple にも自動登録
- NF-04：Apple のアプリ用パスワードは暗号化して保存する
- NF-06：プロバイダの抽象化（T-06 の `CalendarProvider` に `calendar/infra/caldav/` を足す）
- NF-10：Apple CalDAV の Workers からの接続性を、実装着手前に検証する

## スコープ
- やること：
  - 技術検証：Workers（fetch）から iCloud の CalDAV に、アプリ用パスワードで接続できるか。空き／埋まりの取得（free-busy の REPORT など）と、予定の書き込みができるか。予定の中身を読まずに埋まりだけを取れるか
  - 検証の結果を記録し、続けるかを決める（続けるなら仕様書PRを出す）
  - 続ける場合：アプリ用パスワードでの連携・解除、候補・定期の確認・書き込みを、T-06 と同じ流れで Apple に広げる
- やらないこと（スコープ外）：
  - Outlook（Phase 2）
  - T-06 の Google の流れの変更
