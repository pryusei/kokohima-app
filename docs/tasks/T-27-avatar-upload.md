# T-27 アイコン画像のアップロード

## 目的
利用者が自分のアイコンに画像を設定できるようにする。友達の一覧・誘い・募集などで、名前の1文字めの代わりにその画像が出て、誰からの誘いかがひと目でわかる。

## 関係する要件
- F-08：友達追加（招待の受け口で、発行者のアイコンを見せる）
- F-17：退会（アイコンの画像も消す）
- NF-01：R2 を使う
- 未決事項「表示名・アイコン・プロフィール項目、居住エリアの持ち方」（T-15 の「アイコンはプリセットから選ぶ」を、このタスクで「画像をアップロードする」に変える）

## スコープ
- やること：
  - 画像を選ぶ → 端末の中で正方形に切り抜き、256×256 の JPEG にしてから送る
  - API：アイコンの設定（`PUT /me/avatar`）・外す（`DELETE /me/avatar`）・配信（`GET /avatars/{avatarId}`）
  - サーバーでの検証（JPEG の形、大きさ、縦横）と、位置情報などのメタデータの除去
  - 見える範囲：自分、友達、招待リンクを開いた人（発行者のアイコン）。それ以外には画像のURLを出さない
  - 画像の R2 バケット（Terraform）と wrangler のバインディング、URL の署名の鍵（wrangler secret）
  - 使われなくなった画像（変えた・外した・退会）の掃除
  - 設定画面の「アカウント」でのアイコンの変更。T-15 の初回設定の画面でも同じ部品を使う
  - プライバシー ポリシー・利用規約の本文（実装PRで直す。T-19 の決まりで、効力の前に知らせる）
- やらないこと（スコープ外）：
  - アイコンのプリセット（T-15 の12個はやめる）
  - Google・Apple のプロフィール画像の取り込み
  - 切り抜く位置・拡大の調整（中央を正方形に切り抜くだけ）
  - 通報ボタン・自動の画像の検査・運営用の管理画面（削除の求めは問い合わせで受け、運営が手で消す）
  - GIF・動画のアイコン

## 受け入れ条件
- [ ] 設定画面で画像を選ぶと、切り抜いた確認が出て、「この画像にする」で自分のアイコンが変わる
- [ ] 友達の一覧・友達のここ暇・誘い・募集・お知らせ・行きたいで、友達のアイコンに画像が出る。画像がない人・友達でない人は、今の表示名の1文字め
- [ ] 招待リンクを開いた人に、発行者のアイコンが出る
- [ ] 友達でない人には、画像があるかどうかもわからない（`avatarUrl` は常に `null`、配信は404）
- [ ] アイコンを外す・変える・退会すると、前の画像は1時間ほどで R2 から消える
- [ ] 送られた画像の位置情報などのメタデータは保存されない
- [ ] 他人のIDでは取得・更新できないテストがある
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
