# T-44 ログインなしで読める紹介のページ

## 目的
Google の OAuth の審査（pryusei/kokohima-app#199）に要るホームページとして、`https://kokohima.app/` を未ログインでも読める紹介のページにする。JavaScript なしの HTML に、アプリの働きの説明・3つの約束・ログインへの入口・プライバシー ポリシーと利用規約へのリンクを入れる。ログインしている人には今までどおりアプリ（みんな）を出す。あわせて、プライバシー ポリシーの 11. に Google のユーザーデータの扱いの英語の段落を足す（pryusei/kokohima-app#192 のうち審査に足りる最小の範囲。親 #178）。

## 関係する要件
- 要求定義書「残りの論点」（Google の審査）
- 仕様書：docs/specs/T-44-landing.md
- T-01（Cookie）、T-11（画面のつながり）、T-12（振り分け・ビルドの検査・人が行う作業3）、T-19（決めたこと5・10・17・18）、T-25（PWA）、T-28（LINE の中のブラウザ）

## スコープ
- やること：
  - `apps/web/landing.html`（JavaScript なし）と `apps/web/src/landing.css`、vite のビルドの入口に足す
  - Worker の振り分け：`GET`・`HEAD` の `/` で、`__Host-kh_rt` の Cookie がなければ紹介のページ、あれば SPA。`Vary: Cookie`
  - ビルドの検査（`check-web-dist.mjs`）に `landing.html` の検査
  - プライバシー ポリシーの 11. に英語の段落、改定日をデプロイの日に（予告なし）
- やらないこと（スコープ外）：
  - #192 のほかの案（動く見本、安全とよくある質問、「LINE で始める」の主ボタン、`?src=` の数え方、インスタ向けの見せ方）
  - `/privacy`・`/terms` の JavaScript なしの版、ポリシー・規約の全体の英語版
  - Search Console のドメインの確認、同意画面の入力、審査の申込み、動画（人の作業）

## 受け入れ条件
- [ ] JavaScript を切って `https://kokohima.app/`（本番と同じ形の E2E）を開くと、「ここ暇」の見出し・説明・3つの約束・ログイン・プライバシー ポリシー・利用規約へのリンクが読める
- [ ] ログインの Cookie があると、`/` はアプリ（SPA）になる。招待リンク・ほかの画面の経路は変わらない
- [ ] `landing.html` に script がなく、外のオリジンを読まない。ビルドの検査で確かめる
- [ ] プライバシー ポリシーの 11. に、限定使用の英文と空き／埋まり・「ここ暇」カレンダーだけの英語の段落がある。改定日がデプロイの日
- [ ] 他人のIDでは取得・更新できないテストがある（API を足さないので対象外）
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストを追加・更新した
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテスト・本番のビルドが通る
