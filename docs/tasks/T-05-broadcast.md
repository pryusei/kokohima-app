# T-05 募集（暇な人いる？）

## 目的
複数の友達に「この時間、暇な人いる？」を一度に送れるようにする。応じた人の名前は「決める」まで誰にも見せず（募集者にも人数だけ）、決めたら応じた人全員の名前を開示して成立した予定にする。誰も応じなくても、期限切れで静かに終わる。

## 関係する要件
- F-11：募集（応じた人は人数のみ表示。「決める」で応じた人全員へ名前を開示。期限切れは静かに終了し、再募集できる）
- F-13：成立（カレンダーへの登録は T-06。ここでは成立した予定を作るまで）
- F-14：成立後のキャンセル（定型の「やっぱり難しい」のみ）
- 要求定義書「状態遷移とビジネスルール」「ドメイン設計（Broadcast の不変条件）」「悪用対策（誘い・募集あわせて1日20件）」「認可と情報の秘匿（募集の応答者の有無を区別させない）」
- 要求定義書の未決事項「募集で名前が開示された後の『やっぱり行けない』の扱い」（この仕様書で決める）

## スコープ
- やること：
  - 募集の作成（宛先の友達を選ぶ。時間・エリア・ひとこと・リンク・期限）
  - 受け取った募集と自分の募集の一覧・詳細
  - 応じる・応じるのをやめる（決まる前だけ）
  - 決める（募集者だけ、応じた人が1人以上）→ 成立した予定と名前の開示
  - 期限切れ（静かに終わる。通知しない）と、同じ内容での再募集（作成画面に入れて開く）
  - 送信上限を誘いと募集あわせて数える
  - 成立した予定の「やっぱり難しい」を、参加者が3人以上の予定に広げる
  - outbox へのイベントの書き込み（通知とカレンダーは T-06・T-07）
  - 画面（仮）：募集の作成、募集の詳細、誘いタブへの「募集」の一覧
- やらないこと（スコープ外）：
  - カレンダーへの登録（T-06）、通知（T-07）、OGP（T-08）
  - 募集の取り下げ、決めた後の追加の参加
  - Idempotency-Key（別タスク）
  - 最終的な画面デザイン

## 受け入れ条件
- [ ] 友達を選んで募集を送れる。友達でない人は宛先にできない
- [ ] 決める前は、応じた人の名前を誰にも返さない（募集者には人数だけ）。応じた人がいるかどうかを、宛先の人の応答から推測できない
- [ ] 応じた人が1人以上のとき、募集者だけが決められ、応じた人全員と募集者の予定ができ、参加者どうしで名前が見える
- [ ] 期限を過ぎると応じられず、決められず、誰にも通知されない。同じ内容で募集し直せる
- [ ] 誘いと募集をあわせて、直近24時間に20件までしか送れない
- [ ] 決めた後の「やっぱり難しい」が、決定事項どおりに動く
- [ ] 断り・期限切れ・キャンセルを赤やエラー色でなく静かに表示する
- [ ] 他人のIDでは取得・更新できないテストがある
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
