## 概要
ここ暇タブ（`/availability`）が「全体によくない」「『AIで探す』が分かりづらい」「縦に長い」と持ち主から指摘があった。協議用のモック（3案）から、持ち主が「案A：週の帯を土台に、案Cの『空き』の印を混ぜる」に決めた。7日×昼・夕方・夜のマス目を押してここ暇を入れ、件数で高さが伸びない1画面にする。カレンダーの空き（T-06）はマスの青緑の点にし、「AIで探す」は行きたいの欄の頭の「AIでお店を探す」のカードにする。

この PR は、持ち主の決定で、仕様書と実装を同じ PR にする（CLAUDE.md の「1タスク2PR」の例外）。

## API
変えない。今の API をそのまま使う。

| メソッド | パス | 使い方 |
| --- | --- | --- |
| GET | `/api/v1/availabilities` | 今日から14日の自分のここ暇（今のまま） |
| POST | `/api/v1/availabilities` | マスを押す：`{ date, preset }`。時間を細かく決める：`{ startsAt, endsAt }`。取り消しを戻す：下の「3.」 |
| DELETE | `/api/v1/availabilities/{id}` | ここ暇のマスを押す・作った直後の「取り消す」 |
| POST | `/api/v1/recurrence-rules/{id}/exceptions` | くり返しのマスを押す（この日だけ外す） |
| DELETE | `/api/v1/recurrence-rules/{id}/exceptions/{date}` | 外した直後の「取り消す」・くり返しのシートの「戻す」 |
| GET・POST・DELETE | `/api/v1/recurrence-rules` | くり返しのシート（今のまま） |
| GET | `/api/v1/me/presets` | マスの時刻と、どのマスに入るかの計算 |
| GET | `/api/v1/calendar/free-slots` | 点。範囲を今日から7日 → **14日**にする（API の上限の14日の中。次の7日にも点を出すため） |
| GET | `/api/v1/wishes`・`/api/v1/wish-suggestions/quota` ほか | 行きたいの欄（今のまま） |

新しい API はない。どれも今の閲覧者IDでの認可のまま（下の「認可と秘匿」）。

## 振る舞い

### 1. 画面の並び（上から）

3. 週の帯（下の「2.」）と凡例（ここ暇・くり返し・カレンダーで空き。点の凡例は連携しているときだけ）
4. 1行のリンク2つ：「時間を細かく決めて入れる　開始・終了 ›」「くり返し　毎週金 昼　1つ ›」（下の「4.」）
5. 行きたいの欄：見出しと「＋ 行きたいを置く」、「AIでお店を探す」のカード、横にめくる行きたいのカード（下の「5.」）

目標：スマホ（390×844）で、週の帯・「取り消す」・「AIでお店を探す」の入口が1画面に収まる。件数で高さが伸びない（週の帯は21マスで固定、行きたいは横に並べる）。

### 2. 週の帯
- 7日（今日から）×昼・夕方・夜の21マス。列の頭に曜日と日（今日は「今日」と、日を丸で囲む）、行の頭に時間帯の名前と開始の時刻（読み上げは「19:00〜23:00」まで）。時間の区切りは今の昼・夕方・夜の3つ（プリセット。T-41 はあと）。
- 「次の7日」で今日から8〜14日め、「‹」で戻る。14日より先へは進めない（自分のここ暇の一覧の範囲と同じ。60日先までは「時間を細かく決めて入れる」から入れられる）。
- マスは表（`table`）の中のボタン。高さ48px（押せる大きさ44pxを高さで満たす。幅は390pxで約41px）。
- マスの状態と見た目：
  | 状態 | 見た目 | 中の文字 | 押すと |
  | --- | --- | --- | --- |
  | 空き | 面（`surface`）と線 | なし | すぐ作る（`{ date, preset }`） |
  | 空き（カレンダーで空き） | 上と同じに、右上に青緑（`meet`）の小さな点 | なし | 同じ |
  | 手動のここ暇 | 灯り（`lamp-soft`、線は `lamp-line`） | 時間帯どおりなら「暇」、時刻を指定した枠は開始の時刻（「20:30」） | すぐ取り消す（DELETE） |
  | くり返しのここ暇 | 上と同じで、線を点線 | 同じ | すぐ「この日だけ外す」（例外） |
  | ここ暇が2つ以上 | 灯り（全部くり返しなら点線） | 数（「2つ」） | そのマスの一覧のシート（各行に「取り消す」か「この日だけ外す」） |
  | 過ぎた時間帯（空き） | 沈んだ面（`surface-sunken`） | なし | 押せない（`disabled`） |
- 押したらすぐ変える（楽観的更新。data-fetching スキル）。確認は出さない。送っている間のマスは `aria-disabled` にして、もう一度押しても送らない（`disabled` にするとフォーカスを失うため）。失敗したら元に戻して、下に静かな文言（作れない：T-03 の今の文言。取り消し・外す：「変更できませんでした。もう一度お試しください。」）。
- 作った直後は、応答の枠（id つき）で仮の枠を置き換える（読み直しの前に押しても正しい id で消せるように）。そのあと自分のここ暇・みんな・カレンダーの空きを読み直す（`keys.availability.all()`）。
- 過ぎた時間帯：今日のマスで、時間帯の終わりが今以前のもの（作っても T-03 で400になる）。始まっていても終わっていなければ押せる（「今から暇」）。時刻は1分ごとに進める。ここ暇が入っているマスは、過ぎていても押して取り消せる。
- 読み込む前・読めなかったとき・オフラインの間は、マスを押せない（読めないときは上に「読み込めませんでした」と「もう一度」）。
- 作ったマスは、押したときに一度だけ少し弾む（`prefers-reduced-motion` では動かさない）。

### 3. 下に数秒出る一文と「取り消す」
- 下のタブの上（PC では左のナビの右下）に、一文と「取り消す」を出す。見た目はデザインシステムの「Toast」（`ink` の面に `surface` の文字。赤を使わない）。6秒で消す。指やマウスを乗せている間・フォーカスがある間は消さない。読み上げの場所（`role="status"`）はいつも置いておき、中身だけを入れ替える。
- 一文と「取り消す」で起きること：
  | 操作 | 一文 | 「取り消す」 |
  | --- | --- | --- |
  | 空きのマスを押した | 「11/25（水） 夜をここ暇にしました」 | 作った枠を消す |
  | ここ暇のマスを押した | 「11/25（水） 夜のここ暇を取り消しました」 | 作り直す（下） |
  | くり返しのマスを押した | 「11/27（金） 昼だけ外しました（毎週はそのまま）」 | 外した日を戻す |
  | 時間を細かく決めて入れた | 「11/25（水） 20:30〜23:30を入れました」 | 作った枠を消す |
  | 「取り消す」が済んだ | 「元に戻しました」 | 出さない |
- 取り消したここ暇の作り直し：プリセットの名前があり、時刻が今のプリセットと同じなら `{ date, preset }`（名前を残す）。違えば `{ startsAt, endsAt }`（時刻のまま。名前は付かない）。
- 失敗の文言も同じ場所に出す（「取り消す」なし）。

### 4. 昼・夕方・夜に合わない時刻のここ暇と、1行のリンク
- どのマスに入るか：
  - 日付は開始の日付。今日より前に始まった枠（今から暇）は今日のマス。
  - プリセットの名前があれば、その時間帯。
  - なければ（時刻を指定して作った枠）、その日の今のプリセットのうち、重なりの一番長い時間帯。重ならなければ一番近い時間帯。同じなら早い時間帯。プリセットを変えたあとは、変えたあとの時刻で決める。
  - マスの中には開始の時刻を小さく出し、読み上げの名前に開始〜終了（日をまたげば日付つき）を入れる。1つのマスに2つ以上入ったら数を出し、押すと1つずつ選べるシートを開く。どの枠も見えなくならない。
- 「時間を細かく決めて入れる」：押すとシート「時間を決めて入れる」。日付（今日〜60日先）・開始・終了（15分単位）と「入れる」。終了が開始以前なら翌日の時刻（今のまま）。作れたら閉じて、下に「取り消す」を出す。作れなければシートの中に今の静かな文言。昼・夕方・夜のボタンはシートに置かない（週の帯で押す）。
- 「くり返し」：1行に、最初のくり返しの要約（「毎週金 昼」。時刻を指定したくり返しは「毎週土 20:00〜」）と数（「1つ」、なければ「なし」）。押すとシート「くり返し」：今の一覧（「毎週金曜 昼 11:00〜15:00」と「削除」、外した日と「戻す」）と「＋ くり返しを追加する」。追加は同じシートの中でフォーム（今のまま）に切り替え、作ったら一覧に戻る（シートを重ねない）。

### 5. 行きたいの欄
- 見出し「行きたい」の右に「＋ 行きたいを置く」（今のまま）。
- 見出しのすぐ下に「AIでお店を探す」のカード（`meet-soft` の面、`meet` の丸に虫めがね、「AIでお店を探す」と「エリアとしたいことから、お店や場所の候補を探します」、右に「›」）。読み上げの名前は「AIでお店を探す」で、説明に2行めを入れる。押すと T-29 の「行きたいを探す」のシート（中身と流れは今のまま）。出す条件・押せない条件も T-29 のまま（設定がないときは出さない。10件あるときと読み込む前は押せない）。
- 行きたいは横にめくるカード（幅224px、`scroll-snap`）。カードは、ひとこと（3行まで）・エリア・リンク（画像を出さず、タイトルとドメインを1行ずつ）・ボタンを2列×2行（「誘う」「募集する」／「見せる相手」「消す」）。ボタンの並びを固定して、「消す」「見せる相手」が次の行に落ちる崩れを直す。
- 1件もないとき：点線の枠に「行きたいはまだありません」と置き方の案内（今の大きな空の状態より低くする）。

### 6. カレンダーの空き（T-06）
- 連携しているとき（`connected`）だけ、今日から14日分の候補（`GET /calendar/free-slots`）を読み、候補のあるマス（日付とプリセットが同じ）に点を付ける。ここ暇の入っているマスには点を出さない（T-06 が自分のここ暇と重なる候補を返さないため）。
- 読み上げの名前に「カレンダーで空き」を入れる。点は見た目の印だけで、予定の中身（タイトル・場所・参加者）は受け取らないので出しようがない。「AI」とは呼ばない。
- 連携していない人にも同じ週の帯を出す（点と点の凡例が出ないだけ）。
- `needs_reauth`：週の帯の下に「カレンダーの連携が切れています。設定からもう一度連携すると、空いている時間に点が付きます」（「設定」は `/settings/calendar` へのリンク）。`unavailable`：「カレンダーを読み込めませんでした」。回数の上限（429）：「カレンダーの空きは、少し待ってからもう一度開くと出ます」（取り直さない）。どれも静かに出し、週の帯はそのまま使える。

### 7. 読み上げとキーボード
- 週の帯は `table`（見出しは「ここ暇の週の帯。押すとここ暇になります」）。列と行の見出しを `th` にする。
- マスの名前：日付・時間帯・状態・押すと何が起きるか。
  - 空き：「11/25（水） 夜 19:00〜23:00。押すとここ暇にする」（カレンダーで空きなら時刻のあとに「 カレンダーで空き」）
  - 手動：「11/25（水） 夜 ここ暇 19:00〜23:00。押すと取り消す」
  - くり返し：「11/27（金） 昼 くり返しのここ暇 11:00〜15:00。押すとこの日だけ外す」
  - 2つ以上：「11/25（水） 夜 ここ暇が2つ。押すと選べる」
  - 過ぎた：「11/24（火） 昼 過ぎた時間帯」
- ここ暇があるマスは `aria-pressed="true"`、空きは `false`。凡例は見た目の手がかりなので読ませない（`aria-hidden`）。
- マスは Tab で順に移れる（矢印キーでの移動は入れない）。フォーカスの輪は今の共通の輪。

### 8. UI の決まり
- トークン（`lamp`・`meet`・`quiet`・`surface` など）と `apps/web/src/ui/` の部品（`Button`・`BottomSheet`・`LinkCard`・`Note`）を使う。下に出す一文は新しい部品 `apps/web/src/ui/UndoToast.tsx`。
- 取り消し・外す・失敗に赤やエラー色を使わない。
- 同じ性質の Tailwind のクラスを重ねない（状態ごとの見た目は1つの表から1つだけ付ける。点線は `border-style` だけで、線の色とは別の性質）。
- `LinkCard` に `compact`（横のカード用。画像なし・タイトルとドメインを1行ずつ）を足す。ほかの画面の `LinkCard` は今のまま。

## 認可と秘匿
- 閲覧者IDの使い方：新しい API はない。使う API はどれも今のまま、閲覧者IDで自分の行だけを読み書きする（T-03・T-06・T-22・T-29）。
- 他人のデータに届かないことの保証：今の API のテスト（他人の枠・ルール・行きたいには届かない）がそのまま効く。この画面は自分の枠・自分の行きたいだけを出す。
- 区別させない応答：この画面は自分のデータだけで、友達のここ暇は出さない（案C の「友達もひま」は入れない）。
- カレンダー：受け取るのは空いている時間帯（日付とプリセット）だけ。予定の中身は API も画面も持たない。
