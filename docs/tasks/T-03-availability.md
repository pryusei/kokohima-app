# T-03 ここ暇（手動設定・くり返し・時間帯プリセット）

## 目的
自分の「ここ暇」（誘っていい時間）を、時間帯プリセットか開始〜終了で設定し、毎週のくり返しも作れるようにする。友達は、自分に見せてもらっている相手のここ暇を「みんな」と「友達の詳細」で見られるようにする。T-02の公開設定（見せる／見せない）をここで初めて適用する。

## 関係する要件
- F-03：ここ暇の設定（プリセットと開始〜終了の両対応）
- F-04：時間帯プリセット（初期値は昼11〜15時、夕方16〜19時、夜19〜23時。境界は変更可能。変更しても既存の枠は変わらない）
- F-05：くり返し（曜日と時間帯で毎週の基本暇。ルールと例外の2層）
- F-07：公開範囲（見せない相手には「暇がない」と区別できない表示）
- 要求定義書「状態遷移とビジネスルール」：ここ暇は時刻の範囲で保存し、重なりの判定も時刻で行う。友達に見せるときは時刻を必ず併記する
- api-conventions：日時とタイムゾーン（夏時間の丸め方）

## スコープ
- やること：
  - 時間帯プリセットの取得と変更（ユーザーごと）
  - ここ暇の追加（プリセット／開始〜終了）、自分のここ暇の一覧、取り消し
  - くり返しのルールの追加・一覧・削除と、特定の日だけ外す（例外）・戻す
  - 友達のここ暇の一覧（「みんな」。日付の範囲を指定。自分と重なる枠の印つき）と、友達ひとりのここ暇（「友達の詳細」）
  - 公開設定の適用（見せない相手には何も返さず、ここ暇がない相手と同じにする）
  - 画面（仮）：ここ暇タブ（追加・一覧・くり返し・プリセット）、みんな（ホーム）、友達の詳細
- やらないこと（スコープ外）：
  - カレンダー連携（空きの候補表示、実予定による自動取り消し）。T-06
  - 誘い・募集（「あそぼ」「ここどう？」の判定を含む）。T-04・T-05
  - エリア（誘いの項目。要件ではここ暇の項目ではない）
  - タイムゾーンの変更（全員 `Asia/Tokyo` のまま。計算はタイムゾーンを前提に作る）
  - 最終的な画面デザイン

## 受け入れ条件
- [ ] プリセット（昼・夕方・夜）を押すと、その日のその時間帯のここ暇ができる。開始〜終了を指定しても作れる
- [ ] プリセットの境界を変えても、すでにあるここ暇の時刻は変わらない
- [ ] くり返し（例：毎週土曜の昼）を作ると、自分の一覧と友達の画面に毎週の枠が出る。特定の日だけ外すと、その日だけ出なくなる
- [ ] 友達には「夜 19:00〜23:00」のように時刻つきで表示される
- [ ] 「見せない」にした友達には、自分のここ暇が1つも見えず、ここ暇がない友達と同じ応答・表示になる
- [ ] 友達でない人のここ暇は取得できない（存在しない場合と同じ404、または一覧に出ない）
- [ ] 自分の枠と重なる友達の枠に印がつく
- [ ] 他人のIDでは取得・更新できないテストがある
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
