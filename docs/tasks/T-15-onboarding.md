# T-15 初回設定（表示名・アイコン・連携の案内・通知の許可）

## 目的
初めてログインした人が、表示名とアイコンを決め、カレンダー連携と通知の許可を案内され、友達から見える名前が付いた状態でアプリを使い始められるようにする。

## 関係する要件
- F-01（認証）、F-02（カレンダー連携）、F-08（友達追加：発行者の表示名を見て確かめる）
- 要求定義書の未決事項「表示名・アイコン・プロフィール項目、居住エリアの持ち方」
- issue：pryusei/kokohima-app#43

## スコープ
- やること：
  - 表示名とアイコンの初回設定の画面（`/welcome`）と、未設定の人をそこへ案内する仕組み
  - アイコンはプリセットから選ぶ（画像のアップロードはしない）
  - カレンダー連携の案内（あとでもよい）、通知の許可（あとでもよい）
  - 設定画面で、表示名・アイコンの変更と、通知の宛先のメールアドレス（一部を伏せて表示）の確認
  - 要求定義書の未決事項を閉じる
- やらないこと（スコープ外）：
  - 画像のアップロード、居住エリア・自己紹介などのプロフィール項目
  - メールアドレスの手入力での変更（プロバイダから受け取った値だけを使う）
  - 退会（#37）、アカウント連携（#45）、タイムゾーンの変更（#44）

## 受け入れ条件
- [ ] 表示名が未設定の人がログインすると、`/welcome` に案内され、表示名を決めるまでほかの画面へ進めない
- [ ] 招待リンクから来た人も、初回設定のあとに `/invite` に戻り、「友達になる」を押せる
- [ ] アイコンはプリセットから選べ、選ばなくても進める。友達の一覧・招待の受け口に表示される
- [ ] カレンダー連携と通知の許可は「あとで」で飛ばせ、飛ばしても使い始められる
- [ ] 設定画面で、表示名・アイコンを変えられ、通知の宛先が一部を伏せて表示される
- [ ] 他人のIDでは取得・更新できないテストがある
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
