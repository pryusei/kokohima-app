# T-34 「ここどう？」の入口を「みんな」に出し、空の状態を分ける

## 目的
価値の核の「暇がなくても誘える（ここどう？）」を、友達の詳細の奥でなく「みんな」の一番上から使えるようにする。誰のここ暇も見えないときの案内を、友達の有無で分ける。

## 関係する要件
- F-10：個別の誘い（重ならなければ「ここどう？」）
- F-07：見せない相手を、暇がない相手と区別させない
- F-08：友達追加（招待リンク）

## スコープ
- やること：
  - 「みんな」の一番上に「誰を誘う？」の友達全員の顔の列（横にスクロール）。押すとその友達を入れた誘いの作成を開く
  - 空の状態を友達の有無で分ける（友達がいる：顔の列と募るボタン。0人：招待の1つのボタン）
  - 友達の詳細の「ここどう？と誘う」を「誘う」に
- やらないこと（スコープ外）：
  - API の追加・変更
  - 顔の列からの募集・複数選択・並べ替え

## 受け入れ条件
- [x] 「みんな」の一番上に友達全員の顔が並び、押すとその友達を入れた誘いの作成が開き、重ならなければ「ここどう？」になる
- [x] 見せない相手・暇がない相手・ここ暇がある相手が、顔の列で同じ形になる
- [x] 友達がいてここ暇が見えないと、顔の列と「暇な人いる？と募る」が出る。友達が0人だと「友達を招待する」の1つのボタンだけが出て、招待リンクの発行のシートが開く
- [x] 友達の詳細のボタンが「誘う」になる
- [x] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る（CI で確かめる）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
