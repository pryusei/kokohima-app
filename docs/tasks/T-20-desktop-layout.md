# T-20 PC で見るための画面の配置

## 目的
PC のブラウザ（幅1024px以上）で開いたときに、スマホの幅の画面が真ん中に細く出るのをやめ、左の固定のナビと広い中身の配置にする。API・データ・画面の中身（文言・取得の流れ）は変えない。

## 関係する要件
- 要求定義書「形態」：PWA（Web）先行。アプリ未導入の友達もWebで閲覧・返答できる（PC のブラウザで開く友達も含む）
- 要求定義書「デザイン原則」、アクセシビリティ（フォーカス・キーボード操作）
- T-11（画面のつながり・シート・トークン）。docs/specs/T-11-design.md

## スコープ
- やること：
  - 幅1024px以上のときの配置：左のナビ（4つのタブ・お知らせ・設定）、中身の幅を広げる、シートを画面の中央のダイアログで出す
  - 1023px以下は今のまま（下のタブ・下から出るシート）
  - ログイン・招待リンクの受け口・プライバシー ポリシー・利用規約は、中央に置いたまま（ナビを出さない）
  - E2E を「スマホ」と「PC」の2つの画面の大きさで回す
  - T-11 の仕様書の「画面のつながり」に PC の配置を1行足す
- やらないこと（スコープ外）：
  - 一覧と詳細を左右に並べる2列の画面（詳細はダイアログで開く）
  - キーボードのショートカット（Esc 以外）
  - PC 専用の新しい画面・機能、PC 向けの別のデザインのキャンバス
  - タブレット専用の配置（1023px以下はスマホと同じ）
  - PWA のマニフェストの変更

## 受け入れ条件
- [ ] 幅1280pxで開くと、左にナビ（みんな・ここ暇・誘い・友達・お知らせ・設定）が出て、下のタブは出ない。今いる画面に `aria-current="page"`
- [ ] 幅1280pxで、誘いの詳細などのシートは画面の中央のダイアログで開き、「閉じる」のボタン・Esc・後ろの暗い部分で閉じられ、閉じたら開いたボタンにフォーカスが戻る
- [ ] 幅1280pxで、どの画面も横にスクロールしない
- [ ] 幅390pxでは、今と同じ（下のタブ・ヘッダーの鐘・下から出るシート）
- [ ] 画面の幅を変えても、URL・開いているシート・入力中の内容が変わらない
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
