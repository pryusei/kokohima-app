## 振る舞い

### 1. 丸の中身
- 丸の中に、その人のアイコンの画像を出す。画像の URL は上の「API」の `avatarUrl` そのまま（今の `Avatar` と同じ署名つきの URL。作り直さない）。
- 画像の出し方は `apps/web/src/ui/Avatar.tsx` と同じ：`<img alt="" decoding="async" referrerpolicy="no-referrer">`、`object-cover` で丸く切る。読めなかったら（404・期限切れ・通信の失敗）1文字めに戻し、オンラインに戻ったら読み直す。
- 画像がない人（`avatarUrl` が `null`）・読めないときは、今のとおり表示名の1文字め。名前がない人は「？」。
- 退会した人（`withdrawn: true`）は「？」（`avatarUrl` は API がもともと `null`。T-16）。
- 友達でない参加者（募集で成立した予定の参加者どうしで友達でない人）・ブロックした相手・ブロックされた相手は、API が `avatarUrl: null` を返す（T-27「公開プロフィールの `avatarUrl`」。ブロックは友達の解除と同じ扱い。T-33「2.」）ので、1文字め。画面の側で見分けて変えることはしない（画像がない人と同じ形のまま）。
- 「+n」の丸（ほかの参加者が4人以上のとき。T-43「5.」）は今のまま文字だけ。並べ方（自分を左に4つまで、5人以上は「自分・2人・+n」）も、寄ってくる前のずれも変えない。3人以上でも、出ている人の丸は画像。
  - **判断してほしいこと**：画像のない人どうしが同じ1文字めになり、丸だけでは見分けられない場合が残る。選択肢は「受け入れる」「画像がないときは2文字にする」。推奨：受け入れる（下の「〇〇と会える」に名前が出る。丸の中の字を増やすと72pxの丸で小さくなり、T-27 の `Avatar` とも出し方が分かれる）。

### 2. 色の意味は輪で運ぶ
- 丸の外径は今のまま72px（重なり20px）。外から順に、`meet-soft` の3pxの縁（今の縁。重なった丸どうしの切れ目）→ 色の輪3px → 中身（直径60px。画像、または1文字め）。
- 色の輪は、今の丸の地の色と同じく、灯り（`lamp`）から成立の青緑（`meet`）へ変わる（`kh-meet-converge` の今の時間の割り振りのまま：0〜55% が `lamp`、80% 以降が `meet`）。少しふくらんで戻る動きと、丸の並びの後ろの光（`kh-meet-glow`）は今のまま。
- 画像の上に色を重ねない（色の膜・`mix-blend-mode`・`filter` で画像を染めない）。
- 1文字めの丸（画像がない・読めない人、「？」、「+n」）は、今のとおり地の色も `lamp`・`on-lamp` から `meet`・`on-meet` に変わる（輪と地が同じ色になり、今の見た目と同じ）。
- 色はトークンだけ（`lamp`・`on-lamp`・`meet`・`on-meet`・`meet-soft`）。夜のテーマでもトークンのとおり。キーフレームに色の直書きをしない。
- `prefers-reduced-motion: reduce` では、今の共通の決まり（`animation: none !important`）で止まり、最終形＝重なった丸に `meet` の輪（1文字めの丸は `meet` の地）の一枚絵がすぐに出る。止まった形（アニメーションのない状態のスタイル）を `meet` にしておく。

### 3. 画像の読み込みと演出
- 演出は画像を待たない。演出の長さ（丸1.2秒、光1.3秒、文字0.95秒から）とはじまる時刻は変えない。
- 画像が読めるまでは1文字めを出し、読めた時点（`<img>` の `load`）で画像に差し替える。差し替えに動き（フェードなど）は付けない。
- 画像が読めない間も、読めたあとも、丸の大きさ・位置・重なりは変わらない（中身は丸の中の決まった大きさの枠に入れ、`<img>` の大きさを読み込みに頼らない）。
- `<img>` の `loading` は `eager` にする（演出の丸は画面のいちばん上にあり、遅らせる理由がない）。それ以外の属性は `Avatar` と同じ。

### 4. 読み上げ
- 今のまま。丸の並びは飾りで `aria-hidden="true"`、`<img>` の `alt` は空。演出のまとまりは見出し「決まった！」の `region` で、相手の名前は「〇〇と会える」で読む。

### 5. 置き場所
- `apps/web/src/ui/Avatar.tsx`：画像の読み込みの状態（読めなかった URL を覚える・オンラインに戻ったら読み直す）を小さなフック（`useAvatarImage(src)`）に切り出し、`Avatar` と成立の演出の両方で使う。`Avatar` の見た目と振る舞いは変えない。
- `apps/web/src/invitations/MeetMoment.tsx`：`meetMomentDots` の丸に `src`（`avatarUrl`。退会した人と「+n」は `null`）を足し、丸の中身を画像と1文字めで切り替える。自分の `src` は `meQuery` の `avatarUrl`。
- `apps/web/src/index.css`：`.kh-meet-dot` の輪（`border-color`）と `kh-meet-converge` のキーフレームに輪の色を足す。長さと曲線は T-43 のまま（T-56 の直書きの検査で除いているクラスとキーフレームの中だけを変える）。

## 認可と秘匿
- 閲覧者IDの使い方：変えない。相手の画像の URL は、`GET /api/v1/meetups/{id}`（`meetup_participants.user_id = :viewer` の条件。T-04）が、閲覧者と友達である参加者にだけ入れたもの（T-27 の `getHistoryProfiles`）。自分の画像は `GET /api/v1/me`。
- 他人のデータに届かないことの保証：API・クエリを足さないので、新しい経路はない。演出に出る画像は、その予定の参加者のうち、閲覧者が今の画面（予定の詳細の「参加する人」）でもう受け取っている URL だけ。演出のために別の URL を取りに行かない。友達でない参加者・ブロックの相手・退会した人に画像が出ないことは、既存の API のテスト（`apps/api/src/identity/avatar.test.ts`「募集で成立した予定の参加者どうしで、友達でない相手には画像があっても null」など）が守る。
- 区別させない応答：変えない。画像が出ない理由（画像がない・友達でない・ブロック・読めない）は、どれも同じ1文字めで、丸の見た目からは区別できない。退会した人は今のとおり「？」。演出を出す条件（予定の参加者だけ。募集の宛先で参加者でない人には出ない）は T-43 のまま。
- ログ：出すものはない。画像の URL（署名を含む）を画面の外に出さない（今の `Avatar` と同じく `referrerpolicy="no-referrer"`）。
