# T-59 成立した予定は、本人が選んでカレンダーに入れる

## 目的
連携している人の成立した予定は、裏で自動で Google の「ここ暇」カレンダーに書き込まれている（T-06）。持ち主から「勝手に追加するのではなく、追加するかを選べる方がいい」と要望があった。予定の画面に「Googleカレンダーに追加」（Google の追加画面を開く）と「ほかのカレンダーに追加（.ics）」を並べ、自動の書き込みをやめる。

## 関係する要件
- F-13、F-02、NF-02
- 仕様書：docs/specs/T-59-choose-calendar-add.md
- T-06、T-57、T-43、T-16、T-17、T-19、T-11

## スコープ
- やること：
  - 予定の画面の欄（`MeetupCalendarActions`）を、「Googleカレンダーに追加」と「ほかのカレンダーに追加（.ics）」の2つにする
  - Google カレンダーの追加画面の URL を作る関数（`packages/shared`）
  - 自動の書き込みをやめ、前に書いた予定の削除だけを残す
  - 連携のスコープを `calendar.freebusy` だけにする
  - 設定の文言、プライバシー ポリシーと利用規約、要求定義書・関係する仕様書・スキルを直す
  - 単体テスト・E2E
- やらないこと（スコープ外）：
  - 連携の開始の `meetupId` と `return_meetup_id` の片付け
  - 前に書いた予定の削除処理をやめること（前に書いた予定がすべて終わってから）
  - アプリの中のカレンダー、Apple カレンダー（T-09）

## 受け入れ条件
- [ ] 成立中で終わっていない予定にだけ、2つのボタンが出る。連携の有無で変わらない
- [ ] 「Googleカレンダーに追加」の URL に、仕様書のとおりのタイトル・日時・場所・説明が入り、ひとことが入らない
- [ ] 成立しても、アプリから Google に書かない。前に書いた予定は、キャンセル・抜けたときに消える
- [ ] 求めるスコープが `calendar.freebusy` だけ
- [ ] 赤・エラー色を使わない。トークンと `apps/web/src/ui/` の部品を使う
- [ ] 他人のIDでは取得できないテストがある
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストを追加・更新した
- [ ] 仕様書とコードに齟齬がない（要求定義書・T-06・T-57・T-43・T-19・スキルも直した）
- [ ] typecheck・lint・関係するテストが通る
