# T-33 ブロックと通報

## 目的
一般公開（高校生を含む）の前に、嫌な相手をすぐ切れる手段（ブロック）と、運営に知らせる手段（通報）を入れる。どちらも相手には知らせない。

## 関係する要件
- F-09（友達解除）、F-24（ブロックと通報。この仕様で足す）、F-22（問い合わせ。同じ仕組みを使う）
- 要求定義書の未決事項「ひとことの不適切利用への対策」（#49）、受容したリスク
- issue：pryusei/kokohima-app#181（親 #178）

## スコープ
- やること：
  - 友達の詳細・届いた誘い・届いた募集の「…」のシート（見せる／見せない → 友達を解除 → ブロック → 通報）
  - ブロック（友達の解除と同じことをし、ブロックの間はどちらの向きの招待リンクでも友達にならない）と、設定の「ブロックした人」からのやめ方
  - 通報（理由・くわしく・「ブロックもする」・相談先の1行。誘い・募集の中身を一緒に送る）を、問い合わせと同じ outbox → Queue → Slack で運営に届ける
  - プライバシー ポリシー・利用規約の改定と予告、始める日（改定日と同じ日）とデプロイの検査
  - 要求定義書と関係する仕様書（T-02・T-03・T-04・T-05・T-07・T-16・T-17・T-19・T-24）を合わせる
- やらないこと（スコープ外）：
  - 運営者の対応の画面、通報への返事・結果の通知
  - ブロックで進行中の誘い・募集・予定を終わらせること
  - 輪のリンク（未実装）

## 受け入れ条件
- [x] ブロックすると双方の友達一覧から消え、ブロックされた側からは解除と区別できない
- [x] ブロックの間は、どちらの向きの招待リンクを開いても友達にならず、「このリンクは使えません」と同じ表示になる
- [x] ブロックの後に、誘い・募集・招待が届かない
- [x] 通報すると運営の Slack に1通届き、相手には何も届かない。「ブロックもする」ならブロックもされる
- [x] 他人のIDでは取得・操作できないテストがある
- [x] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る（CI で確かめる）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
