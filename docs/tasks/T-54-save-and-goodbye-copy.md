# T-54 保存できたことをボタンで伝える・退会のあとの一文

## 目的
表示名と時間帯プリセットの「保存しました」が小さな灰色の文字だけで気づきにくく、退会のあとの「退会しました。」が悲しい感じがする（持ち主の依頼。本番の画面のスクリーンショット）。保存のボタンを、変えるまで押せず、保存できたらボタンそのものが約2秒「✓ 保存しました」になるようにし、退会のあとの文を感謝の一文にする。

## 関係する要件
- F-17（退会）、デザイン原則2（赤やエラー色を使わない）
- T-11（docs/specs/T-11-design.md）、T-16（docs/specs/T-16-withdrawal.md）、T-31（docs/specs/T-31-display-name-first-step.md）

## スコープ
- やること：
  - `apps/web/src/ui/SaveButton.tsx` に保存のボタンの部品と状態のフックを置き、表示名と時間帯プリセットで使う
  - `Button` に保存できた直後の見た目（variant `saved`、成立の系統のトークン）を足す
  - ログイン画面の退会のあとの文を「今まで使ってくれてありがとう。またいつでも待ってるね。」にする
  - T-11・T-16・T-31 の仕様書の関係する文を直す
- やらないこと（スコープ外）：
  - ほかの保存（行きたいの編集、通知の設定のスイッチ）の見た目
  - 保存できなかったときの見た目、退会の確認の画面の文言

## 受け入れ条件
- [x] 入力が保存済みの値と同じあいだは保存のボタンを押せない。変えると押せる
- [x] 保存できたら、ボタンが約2秒「✓ 保存しました」（成立の色）になり、元に戻って押せなくなる。読み上げは status で伝える
- [x] 2つの画面で同じ部品・同じ動き。動きは付けない（色と文字の切り替えだけ）
- [x] 保存できなかったときの表示は変わらない
- [x] 退会のあとのログイン画面に「今まで使ってくれてありがとう。またいつでも待ってるね。」が静かに出る。表示名は出さない
- [x] 単体テストが追加され、通る
- [x] 仕様書でE2Eの対象にした流れのE2Eテストを直した（CI で回す）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
