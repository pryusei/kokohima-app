# T-08 リンクのプレビュー（OGP）

## 目的
誘い・募集に添えたリンクを、タイトル・説明・画像のカードで見せる。取れなかったときはドメインだけを出す（今の表示のまま）。外部のページを取りに行くので、サーバーから内部のアドレスに届かないこと（SSRF）と、取得の量を抑えることを、仕組みとして守る。

## 関係する要件
- F-15：誘いにURLを1件添付。送信時にOGPを取得・保存し、カードで表示。失敗時はドメインのみ
- NF-02：外部連携（OGP）は Queues 経由の非同期処理とし、失敗時は再試行する
- 要求定義書「OGP取得：ユーザーごとのレート制限、同一URLはキャッシュ」「Link Preview：OGP取得、画像プロキシ」「R2：OGP画像」
- セキュリティ設計（`.claude/claude-security-guidance.md`「外部への取得（OGP）」）：http/https のみ、名前解決後の IP がプライベート・ループバック・リンクローカルなら拒否、リダイレクト先も毎回検査、タイムアウト・サイズ・リダイレクト回数の上限
- issue：pryusei/kokohima-app#47

## スコープ
- やること：
  - `link-preview` コンテキスト（取得・解析・保存・画像の配信）
  - 誘い・募集の作成で outbox にイベントを書き、consumer で取得する
  - 画像を R2 に保存し、アプリの経路から配信する（wrangler に R2 をつなぐ）
  - 誘い・募集・予定の API の応答にプレビューを足し、詳細の画面にカードを出す（仮の画面）
  - E2E 用の偽のサイト
- やらないこと（スコープ外）：
  - 作成画面でのプレビュー（送る前の取得はしない。利用者と決めた）
  - 画像の変換・縮小（そのまま保存して配信する）
  - Terraform の apply、wrangler deploy、本番の R2 の作成（人が行う）

## 受け入れ条件
- [ ] リンク付きの誘い・募集を送ると、しばらくして詳細にタイトル・説明・画像のカードが出る。取れるまでと、取れなかったときはドメインだけ
- [ ] 内部のアドレス（プライベート・ループバック・リンクローカルなど）に向く URL やリダイレクトは取りに行かず、ドメインだけになる
- [ ] 同じ URL を何度送っても、取りに行くのは1回（保存した結果を使う）
- [ ] 画像は R2 から配信され、推測できない ID で、決まった種類の画像だけを返す
- [ ] 誘い・募集を見られない人には、プレビューも見えない（他人のIDでは取得できないテスト）
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
