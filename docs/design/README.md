## デザイン原則
1. 気軽さ：入力は最小、タップで完結。重い確認ダイアログを出さない
2. 気まずくない：断り・期限切れ・キャンセルを赤やエラー色で表示しない
3. 安心：「見せない相手」と「暇がない相手」の見た目を完全に同じにする
