# T-35 通知の見え方を本人が選ぶ

## 目的
プッシュの本文を種類に応じた文にし、ロック画面に名前と日時を出すかを本人が選べるようにする。断り・見送り・取り消し・抜けたは鳴らさない。

## 関係する要件
- F-16（通知）、NF-07（通知の上限と停止設定）
- 要求定義書「受容したリスク」（断りの気まずさ）
- issue：pryusei/kokohima-app#183（親 #178）

## スコープ
- やること：
  - ロック画面の見え方の設定（出さない／名前と日時を出す。初期値は出さない）と、見本を2つ並べて選ぶ画面（友達になった直後の画面と通知の設定）
  - Web プッシュのペイロードの暗号化（RFC 8291、aes128gcm。WebCrypto のみ）と、購読の鍵の保存
  - プッシュの本文（種類に応じた文、選んだ人は名前と日時）と Service Worker の表示
  - 断り・見送り・取り消し・抜けたは、プッシュもメールも送らない
  - 夜（日本時間の22時〜7時）のプッシュを鳴らさない
  - プライバシー ポリシーの改定（予告なし）と、関係する仕様書（T-07・T-19）・要求定義書・invitation-domain スキルを合わせる
- やらないこと（スコープ外）：
  - メールの中身を見え方に合わせること
  - 夜の時間を本人が変えること
  - 1日の上限の見直し

## 受け入れ条件
- [x] 通知を許可するとき（友達になった直後の画面）と設定で、見本の2択から選べ、選ぶと保存される。初期値は「出さない」
- [x] 「出さない」では種類だけ、「出す」では相手の名前と日時が本文に入る。どちらでもひとこと・エリア・リンクは入らない
- [x] 断り・見送り・取り消し・抜けたは、プッシュもメールも届かず、お知らせ一覧に残る
- [x] 本文は RFC 8291 で暗号化され、付録 A の例と一致する
- [x] 夜（日本時間の22時〜7時）はプッシュを鳴らさない
- [x] 他人のIDや鍵では読めないテストがある
- [x] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る（CI で確かめる）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
