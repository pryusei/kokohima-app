# T-56 画面の動きと手触り

## 目的
シートが「パッ」と出て消える、送った・成立した・追加したという手応えがない、押しても反応がない、といった画面の動きの「イマイチなところ」を、動きのトークンと少数の部品でそろえて直す（持ち主の指示書「ここ暇のUIの『動き』と『手触り』を、よくできたアプリの水準に上げる」の M-01〜M-20 と見た目の崩れ2つ）。

## 関係する要件
- 要求定義書「デザイン原則」（断り・期限切れ・キャンセルを赤やエラー色で出さない）、アクセシビリティ（動き・フォーカス）
- 仕様書：docs/specs/T-56-motion.md
- T-11（docs/specs/T-11-design.md）、T-20（docs/specs/T-20-desktop-layout.md）、T-43（docs/specs/T-43-meet-moment.md）、T-54（docs/specs/T-54-save-and-goodbye-copy.md）、T-40（docs/specs/T-40-ima-hima.md）、T-55（ここ暇タブの週の帯。作業中）

## スコープ
- やること（実装PRを3つに分ける）：
  - ① 土台とシート：動きのトークン、`prefersReducedMotion`・`useExitAnimation`・`Collapse`、M-01（シートの出入り）、M-02（つまみと見出しの行を引く）、M-16（シートのスクロールを後ろへ抜けさせない）
  - ② 送る・成立・結果：M-03（送った手応えとシートの差し替え）、M-04（T-43 に足す：ボタン群の退場・バッジのぽん・`meet` の塗りの「成立した予定を見る」）、M-09（アプリに1つの結果の帯）、M-14（送信中のボタン）、M-12（重なる枠が一回だけ灯る）
  - ③ 一覧とナビ：M-05（確認中の殻）、M-06（骨組み）、M-07（下のタブ）、M-08（誘いタブの切り替え）、M-10（自分の操作で増減する行）、M-11（押した感触）、M-13（戻るのある画面の向き）、M-15（未読のバッジ）、M-17〜M-19、見た目の崩れ V-1（誘いの詳細のヘッダー）・V-2（オフラインの帯）
- やらないこと（スコープ外）：
  - アニメーションのライブラリを入れること、振動・音、全画面の祝い
  - T-43 の成立の演出そのものの変更、一覧での成立の演出
  - 中身から引いてシートを下げる操作、誘いタブのスワイプ、T-55・T-40 以外の「元に戻す」

## 受け入れ条件
- [ ] すべての動きが動きのトークンで書かれ、出る動きは入る動きの1段下（約7割）
- [ ] `prefers-reduced-motion` と jsdom では、すべての動きが即時（終わりを `animationend` だけで待たない。保険のタイマーがある）
- [ ] シートの閉じる動きの途中でもう一度押しても、`goBack` は1回だけ
- [ ] 断り・期限切れ・キャンセルに赤・揺れ・✕の動きがない。黄色は決まった場所だけ
- [ ] 見せない相手と暇がない相手、募集の応答者の有無を、動きで区別させない
- [ ] 他人のIDでは取得・更新できないテストがある（API を変えないので対象外）
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストを追加・更新した
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
