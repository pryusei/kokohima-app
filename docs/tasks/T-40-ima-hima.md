# T-40 「今ひま」ワンタップ

## 目的
今から暇なときに、日付と時刻を選ばずに1回押すだけで、見せている友達にここ暇を出せるようにする（issue #188、親 #178）。

## 関係する要件
- F-03：ここ暇の設定
- F-07：見せない相手を、暇がない相手と区別させない

## スコープ
- やること：
  - 「みんな」の一番上に大きな灯りのボタン。押すと確認なしで、今（15分で切り上げ）から3時間のここ暇を作る（日付をまたいでも3時間）
  - 押したあとは「今ひま 〜HH:MMまで」と「やめる」。やめたら5秒「元に戻す」。やめた・時間が過ぎたは灰色の静かな表示
  - 友達の「みんな」の行に「今」の小さな印
  - `POST /api/v1/availabilities` に `{ freeNow: true, startsAt? }`、自分の一覧に `freeNow`
- やらないこと（スコープ外）：
  - 長押しで長さを選ぶ（案C）
  - 友達への通知
  - 新しい公開の経路・マイグレーション

## 受け入れ条件
- [x] 一番上の灯りを押すと、今を15分で切り上げた時刻から3時間のここ暇ができ、「今ひま 〜HH:MMまで」と「やめる」になる。22:10 なら 22:15〜翌 1:15
- [x] やめると灰色の「今ひまをやめました」と「元に戻す」が5秒出て、元に戻すと同じ時刻で戻る。時間が過ぎたら灰色の「おしまい」
- [x] 見せている友達の「みんな」に、ほかの枠と同じ形で出て、「今」の印が付く。見せない相手には出ない（ここ暇がない相手と同じ）
- [x] 他人のIDでは作成・取り消しできない単体テストがある
- [x] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る（CI で確かめる）
- [x] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [x] typecheck・lint・関係するテストが通る
