# T-58 成立の演出の丸にアイコンの画像を出す

## 目的
成立の演出（T-43）の丸の中が表示名の1文字めなので、同じ字で始まる2人（「ゆ」と「ゆき」）が並ぶと誰と誰か分からない（持ち主の指摘）。丸の中にその人のアイコンの画像（T-27）を出し、「灯り→成立」の色は丸の外側の輪で運ぶ。

## 関係する要件
- F-13：成立
- 仕様書：docs/specs/T-58-meet-moment-avatars.md
- T-43（docs/specs/T-43-meet-moment.md）、T-27（docs/specs/T-27-avatar-upload.md）、T-33（docs/specs/T-33-block-report.md）、T-56（M-04）、T-57（演出の中の操作）

## スコープ
- やること：
  - 丸の中に、今の API が返す `avatarUrl`（予定の参加者・自分）の画像を出す。画像がない・読めないときは1文字め、退会した人は「？」、「+n」は文字のまま
  - 色の輪（`lamp` → `meet`）を足し、動きを減らす設定では `meet` の輪の一枚絵
  - 画像を待たずに演出を流し、読めた時点で差し替える。レイアウトは動かさない
  - `Avatar` の画像の読み込みの状態をフック（`useAvatarImage`）に切り出して共有する
  - 単体テスト、T-43 の仕様書の「3.」を直す
- やらないこと（スコープ外）：
  - API・クエリの追加、友達でない参加者への画像の表示
  - 演出の長さ・並べ方・流す条件・「見た」の記録の変更
  - 演出の中の操作（T-57）

## 受け入れ条件
- [x] 画像のある人は丸の中に画像、ない・読めない人は1文字め、退会した人は「？」
- [x] 色の意味が輪の色の変化で伝わり、画像の上に色を重ねない。動きを減らす設定では `meet` の輪
- [x] 画像の読み込みで演出が待たず、丸の大きさ・位置が動かない
- [x] 丸は `aria-hidden` のまま、読み上げは今のまま
- [x] 他人のIDでは取得できない（API を足さないので既存のテストのまま）
- [x] 単体テストが追加され、通る
- [x] 仕様書とコードに齟齬がない（T-43 も直した）
- [x] typecheck・lint・関係するテストが通る
