# T-40 仕様書：「今ひま」ワンタップ

- 状態：実装済み（実装PR。持ち主の決定で、仕様書と実装を同じPRにした）
- タスク票：docs/tasks/T-40-ima-hima.md
- 関係する要件：F-03（ここ暇の設定）、F-07（公開範囲。見せない相手を暇がない相手と区別させない）、要求定義書「価値の核」、docs/specs/T-03-availability.md・T-11-design.md・T-34-kokodou-entry.md、issue #188（親 #178）

## 概要
「今ひま」は、今から3時間のここ暇を、日付も時刻も選ばずに1回押すだけで作るボタン。「みんな」の一番上に大きな灯りのボタンとして置く（協議用モック「今ひまと成立の案くらべ」の案A）。作る枠は既存のここ暇（availability）の手動の枠そのもので、見せる／見せないもそのまま効く。友達へ通知はしない。友達の「みんな」では、今かかっている枠の行に「今」の小さな印を足す。

## 決めたこと（持ち主の決定。協議用モックを見て）
1. **置き場所は「みんな」の一番上の大きな灯りのボタン**（モックの案A）。タブの真ん中（案B）・浮かぶ丸（案C）にはしない。
2. **押すと確認なしで作る。** 開始は今を15分の区切りに切り上げた時刻（ちょうど区切りならその時刻）、長さは3時間。友達へ通知はしない（outbox に何も書かない）。
3. **日付をまたいでも3時間のまま**（22:10 に押すと 22:15〜翌 1:15）。24:00 で切らない。
4. **押したあとは「今ひま 〜HH:MMまで」と「やめる」。** 終わりが開始と別の日なら「翌」を付ける（「今ひま 〜翌01:15まで」）。
5. **友達の一覧（「みんな」のここ暇の一覧）では、「今」の小さな印を足す。** 通知はしない。見せない相手と、ひまでない相手は区別できない（どちらも行が出ないので、印も出ない）。場所は出さない（ここ暇に場所はない）。
6. **「やめる」のあとに5秒、「元に戻す」を出す**（持ち主から任された。この形で進め、PR に書く）。やめた・時間が過ぎたは、灰色の静かな表示（`bg-quiet-bg`・`text-quiet-ink`）で、赤を使わない。
7. **長押しで長さを選ぶ（モックの案C）は今回入れない**（あとで）。
8. **新しい公開の経路を作らない。** 今ひまは `POST /api/v1/availabilities` の入力の1つの形として作り、友達へは既存の `GET /api/v1/friend-availabilities`・`GET /api/v1/friends/{friendId}/availabilities` で、ほかの枠と同じ形で返す。
9. **「今」の印は、作り方ではなく時刻で決める**（実装での判断。PR の「判断してほしいこと」）。友達の枠に「今ひまで作った」かどうかは返さない。T-03 の「友達の枠には作った方法を返さない」を守るため。印を付けるのは、見えている枠のうち「今を15分で切り上げた時刻までに始まり、まだ終わっていない」枠（今ひまで作った枠は、作った直後から終わるまでいつもこれに当たる）。今かかっている夜のここ暇などにも付く。
10. 友達が0人のときは今ひまのボタンを出さない（T-34 決めたこと3の「招待の1つのボタンだけ」のまま。見せる相手がいないため）。

## API
`api-conventions` スキルに従う。新しいパスは作らず、T-03 の `POST /api/v1/availabilities` の入力に形を1つ足し、自分の一覧の出力に項目を1つ足す。スキーマは `packages/shared/src/schemas/availability.ts`。

| メソッド | パス | 認証 | 入力（Zodスキーマ名） | 出力 | 主なエラー |
| --- | --- | --- | --- | --- | --- |
| POST | `/api/v1/availabilities` | Bearer | JSON：`createAvailabilityRequestSchema` の `{ freeNow: true, startsAt? }`（足す形） | 201：`myAvailabilitySchema`（`freeNow: true`、`label: null`） | 400（`startsAt` が先の時刻・15分の区切りでない・終わりが今以前、`freeNow` が true でない、余計な項目）、409 `invalid_state`（自分の終わっていない手動の枠と重なる、未来の枠が上限） |
| GET | `/api/v1/availabilities` | Bearer | （変えない） | 200：`myAvailabilitySchema` に `freeNow`（足す項目） | （変えない） |
| DELETE | `/api/v1/availabilities/{id}` | Bearer | （変えない。「やめる」に使う） | 204 | 404（他人の枠・存在しないID） |

### 入力
- `{ freeNow: true }`：サーバーの今から決める。開始＝今を15分で切り上げた時刻、終了＝開始＋3時間。クライアントの時計は使わない。
- `{ freeNow: true, startsAt }`：「元に戻す」のときだけ送る。やめた今ひまと同じ開始で作り直す。`startsAt` は15分の区切りで、今を15分で切り上げた時刻以前、かつ `startsAt`＋3時間が今より後でなければ400（先の時刻の今ひまを作らせない）。
- 余計な項目（`userId` など）は400（`strict`）。他人を指して作ることはできない。作る枠の持ち主は、いつも `requireAuth` の閲覧者。
- `Idempotency-Key` は T-10 のとおり（同じ内容の送り直しは同じキー）。

### 出力
- `myAvailabilitySchema` に `freeNow: boolean` を足す。今ひまで作った手動の枠だけ `true`。くり返しの展開と、ほかの作り方の手動の枠は `false`。古いサーバーの応答に項目がなくても読めるよう、スキーマは既定値 `false` を持つ。
- 今ひまの枠の `label` は `null`（開始〜終了で作った枠と同じ）。
- 友達に返す形（`friendAvailabilitySchema`・`slotSchema`）は変えない。`freeNow` を返さない。

## データ
- テーブルと列は変えない。マイグレーションなし（予約していた 0021 は使わない）。
- 今ひまで作った枠は `availabilities.label` に `'free_now'` を入れて見分ける（T-03 の `label` の列は文字列で、制約がない）。API の `label` には出さない（`day`・`evening`・`night` のどれでもない値は `null` にする今の変換のまま）。
- 今ひまの枠も手動の枠なので、T-12 の掃除・T-16 の退会・T-06 のカレンダーの自動取り消しは今のまま効く。
- ブラウザには何も保存しない（「元に戻す」の開始時刻は画面の状態だけに持つ）。
- 保存・送信する情報の種類は変わらない（ここ暇の時刻だけ）ので、プライバシー ポリシーと利用規約は直さない。

## 振る舞い

### 作る（サーバー）
- 開始・終了は `domain` の純粋な関数 `freeNowSlot(now, startsAt?)` で決める（`apps/api/src/availability/domain/validation.ts`）。15分の区切りは UTC のミリ秒で切り上げる（日本時間を含め、時差が15分の倍数のタイムゾーンでは現地の区切りと同じ）。
- できた枠は T-03 の手動の枠の検証（15分単位・30分以上・24時間以下・終わりが今より後・60日以内）を通る。
- 重なりと上限の判定は T-03 と同じ1つの文（`insertManualWithinLimits`）。自分の終わっていない手動の枠と1分以上重なれば409。2回押しても1つしかできない。くり返しの展開とは重なってもよい（友達に返すときに1つにまとめる。T-03）。

### 「みんな」（`/`）の画面
上から順に（友達が1人以上、または友達の一覧を読み込み中・読めないとき。T-34 の並びの一番上に足す）：
1. 今ひま（`aria-label="今ひま"` の節）。自分の一覧（`GET /api/v1/availabilities`。ここ暇タブと同じ `mineQuery` のキャッシュ）から、`freeNow` で終わっていない手動の枠を探す。友達の一覧・ここ暇の一覧と並列に読む。
   - ないとき：大きな灯りのボタン（`bg-lamp`）。「今から3時間ひま」と、その下に「15:30〜18:30 ・ 押すとすぐ灯る」（今押したときの目安。日付をまたげば「22:15〜翌01:15」）。押すと確認なしで作る。作れたらすぐ下の形に変え、ここ暇のクエリ（`keys.availability.all()`）を取り直す（「みんな」の重なりの印も変わるため）。自分の一覧を読み込み中・送信中・オフラインの間は押せない。
   - あるとき：灯りの薄い帯（`bg-lamp-soft`・`border-lamp-line`）に「今ひま 〜18:30まで」（決めたこと4）、「見せている友達に、時刻だけ出ています。通知はしていません」、「やめる」のボタン。
   - 「やめる」：楽観的更新で、押したらすぐ自分の一覧のキャッシュから消し、灰色の「今ひまをやめました」と「元に戻す」を5秒出す（`DELETE /api/v1/availabilities/{id}`）。やめられなかったら、元に戻して「やめられませんでした。もう一度お試しください」（静かな文言）。
   - 「元に戻す」：`{ freeNow: true, startsAt: <やめた今ひまの開始> }` を送り、作れたら「今ひま 〜HH:MMまで」に戻す。作れなければ（時間が過ぎた・ほかの枠と重なった・通信できない）「元に戻せませんでした」。やめる送信の途中とオフラインの間は押せない。5秒たつと消え、灯りのボタンに戻る。
   - 時間が来たら（画面を開いている間に終わりの時刻を過ぎたら）、灰色の「18:30で今ひまはおしまい」を5秒出し、ここ暇のクエリを取り直してから灯りのボタンに戻す。開いたときにもう終わっていた今ひまには何も出さない。
   - 作れなかったとき：409 は「この時間には、もうほかのここ暇があります」、それ以外は「灯せませんでした。通信状態を確認して、もう一度お試しください」。どちらも静かな文言で、ボタンは出したまま。
2. 「誰を誘う？」の顔の列（T-34。変えない）。
3. 「暇な人いる？と募る」（変えない）。
4. ここ暇の一覧（「みんなのここ暇」）。行の表示名の横に「今」の印（決めたこと9）。印は灯りの色の小さな丸い札（`bg-lamp`・`text-on-lamp`）で、読み上げは「今ひま」（「ひま」は `sr-only`）。時刻は30秒ごとに取り直して印と灯りのボタンの目安の時刻を描き直す（API は呼ばない）。
5. 友達の行きたい（T-22。変えない）。
- 友達が0人：T-34 のまま（今ひまのボタンは出さない。決めたこと10）。

### ほかの画面
- ここ暇タブの「自分のここ暇」には、今ひまの枠もほかの手動の枠と同じく時刻で出て、「取り消す」で消せる。
- 友達の詳細の枠の一覧は変えない（印を付けない）。

## 認可と秘匿
- 閲覧者IDの使い方：作成・一覧・取り消しは T-03 のまま、`requireAuth` の閲覧者IDだけを使う。入力に持ち主の項目はなく、余計な項目は400。
- 他人のデータに届かないことの保証：
  - 他人の今ひまの取り消しは、存在しないIDと同じ404（`WHERE id = ? AND user_id = :viewerId`）。
  - 友達の今ひまは、T-03 の「前提」の3条件を SQL に入れた今の取得で返す。新しい読み取りの経路はない。
- 区別させない応答：
  - 見せない相手・ここ暇がない相手・友達でない人には、今ひまも出ない（ほかの枠と同じく結果に含まれない）。印も出ない。
  - 友達の枠の形は変えない（`freeNow` も作り方も返さない）。「今」の印は、見えている枠の時刻だけから画面で決める。
- 通知・ログ：通知はしない。ログに枠の時刻や相手のIDを出さない（T-03 のまま）。
