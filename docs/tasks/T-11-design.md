# T-11 画面の最終デザインへの置き換え

## 目的
T-01〜T-08 で「仮」として作った画面を、デザインシステムと MVP 画面のデザインに合わせて置き換える。画面のつながり（4つのタブ、ヘッダーのお知らせ、下から出るシート、設定）もデザインに合わせる。

## 関係する要件
- 要求定義書「デザイン原則」：気軽さ（タップで完結）、気まずくない（断り・期限切れを赤で出さない）、安心（見せない相手と暇がない相手を区別させない）
- NF（アクセシビリティ）：文字のコントラスト4.5:1、押せる部品は44px以上、フォーカスの輪、動きを減らす設定への対応
- issue：pryusei/kokohima-app#51（最終デザインの差し替えとオフライン対応）

## スコープ
- やること：
  - デザインシステムのトークン（色・文字・余白・角丸・影）を `apps/web` に入れ、ライトと夜（ダーク）のテーマを端末の設定で切り替える
  - 共通の部品（ボタン、バッジ、ここ暇のチップ、誘い・募集のカード、リンクのカード、シート、タブバー、ヘッダー、スイッチ、トースト、空の状態、読み込み中・エラー・オフライン）を作る
  - 既存の全画面を、デザインに合わせて置き換える
  - ナビを4つのタブ＋ヘッダーのお知らせにし、設定のトップ・時間帯プリセット・アカウントの画面を設定の下にまとめる
  - オフラインのときの表示（キャッシュはしない）
- やらないこと（スコープ外）：
  - 初回設定の流れ（#43）、アイコンの登録、退会（#37）、アカウント連携（#45）、Appleカレンダー（T-09）
  - テーマを手で切り替える設定
  - オフラインでも読めるようにするキャッシュ
  - API・データの変更

## 受け入れ条件
- [ ] すべての画面が、デザインシステムのトークンと部品で描かれ、仮の見た目（Tailwind の `slate` などの直書き）が残っていない
- [ ] 端末が夜（ダーク）の設定なら、全画面が夜のテーマになる
- [ ] 断り・期限切れ・見送り・締め切り・やっぱり難しい・失敗の表示に、赤やエラー色が使われていない（テストで確かめる）
- [ ] 下のタブは「みんな・ここ暇・誘い・友達」の4つで、お知らせはヘッダーから開け、未読の数が出る
- [ ] 誘い・募集・予定・友達の詳細と作成は、下から出るシートで開き、閉じると元のタブに戻る
- [ ] オフラインになると「オフラインです。つながると最新の内容になります」が出て、送る操作のボタンが押せなくなる
- [ ] 単体テストが追加され、通る
- [ ] 仕様書でE2Eの対象にした流れのE2Eテストが通る
- [ ] 仕様書とコードに齟齬がない（仕様の変更は仕様書に反映済み）
- [ ] typecheck・lint・関係するテストが通る
