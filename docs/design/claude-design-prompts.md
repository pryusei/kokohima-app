# Claude Design用プロンプト

2回に分けて渡す。①でデザインシステムを作って確定させてから、②で画面を作る。

## ① デザインシステム

```
友達を誘う気まずさをなくすWebサービス「ここ暇」のデザインシステムを作ってください。
PWA（スマホ中心のWebアプリ）で、地元の友達同士が使います。

## サービスの概要
- 「ここ暇」＝「この時間なら誘っていいよ」という許可のサイン。カレンダーと連携して設定する
- 友達のここ暇を見て「あそぼ」と誘える。暇でなくても「ここどう？」と誘える
- 複数人に「暇な人いる？」と募集できる。応じた人は人数だけ見え、募集者が「決める」と名前が開示される
- 返答は「行く／今回は難しい／この時間なら」の3つだけ。断りの理由は伝わらない

## デザイン原則（最優先で守ってください）
1. 気軽さ：入力は最小限、タップで完結。重い確認ダイアログを避ける
2. 気まずくない：断り・期限切れ・キャンセルを赤やエラー色で表示しない。失敗ではなく静かな状態として見せる
3. 安心：「見せない設定の相手」と「暇がない相手」の見た目を完全に同じにする

## トーンと方向性
- 夜に窓の灯りがともるような、温かくて静かな雰囲気。ここ暇の枠が「灯り」として光るのが唯一の印象的な要素で、それ以外は控えめに
- 方向性の参考：濃紺の文字、淡い青みのグレーの背景、ここ暇や重なりを示すランプのような黄色、成立を示す落ち着いた緑
- 丸みのある日本語フォント（Zen Maru Gothicなど）
- ライトとダークの両方

## 作ってほしいもの
1. カラートークン：意味で名前を付ける（例：ここ暇、重なり、成立、控えめな状態、背景、面、文字、補助文字、線）。ライト／ダーク両方
2. タイポグラフィ、余白（4の倍数）、角丸、影、動きのトークン
3. コンポーネントと、その全状態：
   - ここ暇の枠のチップ（通常／自分と重なっている）
   - 誘いのカード（個別・募集 × 受信・送信 × 返事待ち・成立・今回は難しい・この時間なら・期限切れ・自動で断った）
   - 返答ボタン群（行く／今回は難しい／この時間なら）
   - 募集の人数表示（名前を出さず人数だけ）
   - リンクのOGPプレビューカード（取得中／成功／失敗）
   - ボトムシート、タブバー（4タブ）、アバター、スイッチ、日付と時間帯の選択チップ、トースト、空の状態
4. 文言ガイド：断り・期限切れ・エラーの言い回しの調子と例

コンポーネントは、状態の違いが一覧で比較できるように並べてください。
```

## ② 画面

```
先ほど作った「ここ暇」のデザインシステムを使って、MVPの画面を作ってください。
スマホ縦（幅390px前後）を基準にします。

## メインタブ（4画面）
1. みんな：日付ごとに、友達のここ暇の枠を並べるタイムライン。自分と重なっている枠は光らせる。上部に「暇な人いる？と募る」ボタン
2. ここ暇：カレンダー連携の状態、カレンダーの空きから出した候補（ワンタップで設定）、くり返し（毎週土曜の昼など）、自分のここ暇の一覧
3. 誘い：受信・送信・成立の切り替え。誘いのカードを状態ごとに表示
4. 友達：招待リンクの発行、友達一覧と「自分の暇を見せる」スイッチ

## シート（下から出る画面）
5. 個別の誘い作成：日付、時間帯（プリセット＋細かく指定）、エリア（任意）、ひとこと、リンク（任意、OGPプレビュー表示）、返事の期限
6. 募集作成：宛先の複数選択以外は5と同じ。「応じた人は人数だけ表示」の説明を添える
7. 受信した誘いの詳細と返答。「この時間なら」で別の時間を選ぶ状態も
8. 送信した募集の詳細：人数だけ表示、「決める」ボタン
9. 成立した予定：参加者、カレンダー登録の状態、「やっぱり難しい」
10. 友達の詳細：見えているここ暇、「ここどう？と誘う」、友達の解除（相手に通知されない旨を明記）

## 入口
11. 招待リンクを開いたときの画面（未ログイン）
12. ログイン（GoogleとSign in with Apple）

## 守ってほしいこと
- 断りや期限切れを赤で表示しない
- 「見せない相手」と「暇がない相手」の見た目を区別しない
- 各画面の空の状態も1つずつ作る
```
